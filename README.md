# Gonçalo Transportadora

Landing page institucional da Gonçalo Transportadora.

Site desenvolvido para apresentar serviços, área de atuação, veículos, diferenciais e facilitar solicitações de cotação via WhatsApp.

## Tecnologias
- HTML
- CSS
- JavaScript

## Identidade
